# AgriSense — AI Agriculture & Environment Intelligence App

## Run the website
1. Extract the ZIP file.
2. Open the `AgriSense_Website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.

## Included features
- Crop image upload and drag-and-drop preview
- Browser-side visual color analysis (green cover, yellow stress, dark spots, dry/brown area)
- Crop and growth-stage selection with a heuristic field report
- Actions, reasoning and limitations tabs
- Farmer advisory chat with common topic responses
- Weather/environment guidance based on entered conditions
- Optional browser geolocation
- English, Hindi and Telugu language selector
- Responsive layout for desktop and mobile

## Important limitation
This is a front-end demonstration. Image analysis uses simple color heuristics; it is **not** a trained disease-detection model or laboratory diagnosis. Chat responses are rule-based, and weather advice uses values entered by the user rather than a live weather service. Confirm treatment decisions with a qualified local agriculture expert.
